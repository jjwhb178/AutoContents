# SW 요구사양서 (Software Requirements Specification)
**프로젝트명:** MoneyDaddy AI Content Factory  
**기준 문서:** AutoContents.md (Ver 10.0)  
**문서 버전:** 2.0 (Hybrid Automation Patch)  
**작성일:** 2026-05-06

---

## 1. 목적 및 범위

### 1.1 목적
AutoContents.md(Ver 10.0)를 시스템 요구사양의 원천으로 삼아, MoneyDaddy AI Content Factory가 반드시 충족해야 할 기능적·비기능적 요구사항을 정의한다.

### 1.2 범위
- 매일 오전 7시 전 블로그·영상 콘텐츠 자동 생성 및 발행 파이프라인 전체
- 네이버 블로그 포스팅 / 유튜브 영상(PPT 기반 MP4) / TTS 음성 생성
- AI 에이전트 기반 콘텐츠 창작 (Dual-Agent 구조)

---

## 2. 기능 요구사항 (Functional Requirements)

| ID | 요구사항 | 우선순위 |
|----|----------|----------|

| FR-01-3 | 미국 주요 섹터 ETF(SOXX, QQQ, XLK, XLF, XLE, XLV) 전일 수익률을 수집해야 한다. | 필수 |
| FR-01-4 | 한국 주도 섹터(반도체, AI/소프트웨어, 2차전지, 바이오, 로봇/자동화, 자동차, 방산, 금융) 수익률을 수집해야 한다. | 필수 |

| FR-01-7 | 네이버 경제 뉴스, 한국경제신문 등에서 환율 임계점, 기관 수급 등 '시장 구조적 결함'을 파악할 텍스트 정보를 소싱해야 한다. | 필수 |

| FR-02-4 | Sector Pivot 감지 시 전체 콘텐츠 서사를 즉시 해당 섹터 중심으로 전환해야 한다. | 필수 |

### FR-03 머니대디 스코어
| ID | 요구사항 | 우선순위 |
|----|----------|----------|

### FR-04 네이버 블로그
| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| FR-04-1 | 블로그 본문은 MD 배제 및 가로 구분선을 활용하며, 모바일 가독성을 위해 문단은 3~4줄로 끊고 핵심 통찰은 볼드(Bold) 처리한다. | 필수 |
| FR-04-2 | 블로그에는 정확히 4장의 이미지가 포함: 1)뉴스 현장 2)통계 그래프 3)미국-한국 상관관계 인포그래픽 4)기술적 분석 근거 차트 | 필수 |
| FR-04-3 | 블로그 이미지 생성 시 텍스트, 숫자(한/영, 상품명 등)를 절대 포함하지 않고 Slate Blue & Gold 톤의 순수 시각적 메타포에 집중해야 한다. | 필수 |
| FR-04-4 | 블로그 이미지 4번에는 QR 코드가 자동 합성되어야 한다. | 필수 |
| FR-04-5 | 시스템 아키텍트 관점의 고유 서사(80%)를 반영하여 네이버 DIA+ 로직에 최적화해야 한다. | 필수 |

### FR-05 PPT 설계 및 영상 대본
| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| FR-05-1 | PPT 18페이지 기승전결: [起]1~3(도입) / [承]4~9(원인/대조) / [轉]10~15(반전/시나리오) / [結]16~18(종합 분석/마무리). | 필수 |
| FR-05-2 | [차트 자동화] 텅 빈 플레이스홀더 대신 Matplotlib을 활용해 실제 시장 데이터를 반영한 차트를 PPT에 자동 삽입해야 한다. | 필수 |
| FR-05-3 | PPT 디자인은 Minimalist & Bold: 텍스트 최소화, 핵심 수치 거대 배치, Z-pattern 레이아웃. | 필수 |
| FR-05-4 | PPT 컬러 팔레트는 슬레이트 블루 & 골드 톤. | 권장 |
| FR-05-5 | 해설 대본은 1.4배속 낭독을 고려하여 짧고 단호하게 끊어치며, 각 슬라이드 시작 전 `[Slide XX]` 태그로 1:1 동기화한다. | 필수 |
| FR-05-6 | 해설 대본 총 길이는 3,500자 이상(PPT 합산 기준)이어야 하며, 블로그 본문은 2,500자 이상을 유지해야 한다. | 필수 |
| FR-05-7 | 대본의 모든 괄호·기호는 제거, 영문·숫자는 한국어 발음으로 치환되어야 한다. | 필수 |

### FR-06 음성 및 영상
| ID | 요구사항 | 우선순위 |
|----|----------|----------|

## 4. 데이터 요구사항

### 입력 (data/raw_market_data.json)
- VIX, VIX_chg, TNX_10Y, USD_KRW, USD_KRW_chg
- KOSPI, KOSDAQ, NASDAQ, NASDAQ_chg, SP500, SP500_chg
- Fear_Greed, Fear_Greed_Rating
- us_sectors: {반도체(SOXX), 빅테크(QQQ), AI/IT(XLK), 금융(XLF), 에너지(XLE), 헬스케어(XLV)}
- kr_sectors: {반도체, AI/소프트웨어, 2차전지, 바이오, 로봇/자동화, 자동차, 방산, 금융}
- top_kr_sectors: [(섹터명, 수익률) x3], bottom_kr_sectors: [(섹터명, 수익률) x2]
- sector_volume_surge: [{name, volume_ratio}]  ← Sector Pivot 입력

### 출력 (outputs/YYYY-MM-DD/)
- daily_content_draft.md, daily_strategy_v2_5.pptx, daily_video.mp4
- thumbnail_A_rational.png, thumbnail_B_emotional.png
- verification_report.md, audio/ (슬라이드별 MP3 + full_narration.mp3)
