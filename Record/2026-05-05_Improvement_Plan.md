# 📅 2026-05-05 머니대디 시스템 결함 분석 및 차기 개발 계획서

오늘 분석된 시스템의 8가지 핵심 결함과 이를 해결하기 위한 '머니대디 2.0 하이브리드 자동화' 개발 로드맵을 정리합니다. 내일 작업은 본 문서를 기준으로 Phase 1부터 순차적으로 진행합니다.

---

## 1. 현재 시스템 핵심 결함 (Issue Analysis)

### 🔴 미디어 및 콘텐츠 품질 관련
1. **PPT 대본 분량 미달 (3,500자 미충족):** 단일 JSON 응답 내에서 방대한 텍스트 생성 시 발생하는 AI의 요약 본능 및 토큰 제한 이슈.
2. **환율 데이터 과적합 (Overfitting):** 주제와 무관하게 환율 지표에 집착하여 논리를 억지로 연결하는 프롬프트 오염 현상.
3. **조악한 PPT 시각화:** 진짜 PPT 템플릿을 쓰지 않고 코드로 도형을 그리는 하드코딩 방식으로 인한 디자인 완성도 저하.
4. **불필요한 이미지 생성 & 토큰 낭비:** 슬라이드를 텍스트 기반 PPT로 만들지 않고 불필요하게 이미지 위주로 접근하려는 비효율적 설계.
5. **저질 썸네일 & 텍스트 깨짐:** 이미지 생성 AI의 한계로 인해 한글 텍스트가 잘리거나 외계어로 출력되는 현상.
6. **블로그 이미지 문맥 부조화:** 추상적 경제 개념을 AI가 잘못 해석하여 기괴한 실사 이미지를 생성함.

### 🟡 시스템 및 GUI 관련
7. **GUI 레이아웃 비효율:** 세로 1열 배치로 인해 와이드 모니터 공간 낭비 및 가독성 저하 (2열 구조 필요).
8. **영상/음성 합성 싱크 오류:** FFmpeg 병합 과정에서의 오디오 트랙 누락으로 인한 묵음 영상 생성 버그.

---

## 2. 보완 개발 계획 (Master Improvement Plan)

### 🚀 Phase 1: GUI 재설계 및 콘텐츠 로직 강화
- **[GUI 2.0]** 좌측(컨트롤/입력) - 우측(프리뷰/로그) 2열 구조로 전면 개편.
- **[대본 분량 강제]** '구조 기획'과 '대본 작성'을 분리하여 2-Step으로 생성 (3,500자 확보).
- **[데이터 필터링]** 메인 키워드와 연관된 시장 데이터만 AI에게 선별적으로 제공하여 '환율 억지 연결' 원천 차단.

### 🎨 Phase 2: 마스터 템플릿 기반 PPTX 혁신
- **[Template Engine]** 실제 디자인된 `.pptx` 파일을 로드하여 텍스트만 프로그래밍으로 치환하는 방식으로 전환.
- **[Chart Automation]** 텅 빈 상자 대신 Matplotlib 등을 활용해 실제 데이터를 반영한 차트를 PPT에 자동 삽입.

### 🖼️ Phase 3: 하이브리드 시각 자료 시스템
- **[Hybrid Thumbnail]** AI는 '배경'만 생성하고, 텍스트는 파이썬(PIL)이 진짜 폰트로 그 위에 선명하게 인쇄하는 방식 도입.
- **[Metaphor Images]** 블로그 이미지를 '추상적 3D 오브젝트' 스타일로 고정하여 문맥 이질감 최소화.

### 🎬 Phase 4: 미디어 합성 안정화
- **[Sync Debugging]** 슬라이드 표시 시간을 오디오 길이에 동적으로 맞추는 정밀 타이밍 로직 패치.
- **[FFmpeg Fallback]** 합성 실패 시 즉각 에러 로그를 리포트하고 재시도하는 안전 장치 추가.
